입장 전

가족 코드 입장

직접 입력

사진/영상 첨부

직접 입력 기록에 사진·영상을 최대 3개까지 첨부한다. 사진/짧은 영상 권장. 1개당 50MB 초과 파일은 막는다.

로그 붙여넣기

날짜 헤더 뒤에 시간 기록을 붙여넣으면 날짜별로 기록과 요약을 묶어 미리보기/저장한다. 메모 안의 예정일·2/2·1/3은 날짜로 보지 않는다.

가져오기 기본 연도

연도가 없는 날짜, 예: 6/20 토, 6월 20일 기록을 어느 해로 저장할지 정한다. 2025.6/20처럼 연도가 있으면 그 연도를 따른다.










  
Apple 메모 선택 → 케어로그 동기화

  
아이폰 단축어에서 내 메모 중 원하는 메모 하나를 직접 선택해 전달할 수 있습니다. 전용 폴더·특정 제목·하루별 파일이 필요하지 않습니다. 한 메모에 여러 날짜가 있어도 각 날짜별로 나누어 기록합니다.

  
중요: 자동 저장은 하지 않습니다. 메모 선택 후 이 화면의 「선택한 메모 확인·동기화」를 누르고 날짜·건수를 확인해야 Firebase에 저장됩니다. 메모 내용을 다른 앱에서 복사했을 때 잘못된 데이터를 넣지 않도록 하기 위함입니다.

  

    
    
  

  

    
    
    
  

  
단축어에 처음 한 번 넣을 고정 주소 — 메모 내용이나 연결 토큰을 주소에 넣지 않습니다.

수신 상태

  
아직 받은 Apple 메모가 없습니다.

  

    
    
    
  

  
날짜가 여러 개인 메모도 날짜·시간별로 나눠 처리합니다. 동일한 내용은 건너뛰고, 이전에 단축어로 저장한 기록의 정정만 반영합니다. 삭제된 메모 행은 Firestore에서 자동 삭제하지 않습니다. 날짜·시간·종류를 변경하면 중복이 생길 수 있으므로 검토가 필요합니다.
